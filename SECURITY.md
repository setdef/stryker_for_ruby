# Security policy

## Report a vulnerability privately

Report a vulnerability in **Stryker (for Ruby)** through GitHub's private vulnerability reporting, never in [the Discussions](https://github.com/setdef/stryker_for_ruby/discussions), in an email thread, or anywhere else others can read it:

1. Open [the repository's Security tab](https://github.com/setdef/stryker_for_ruby/security) and choose **Report a vulnerability**, or go straight to [a new private advisory](https://github.com/setdef/stryker_for_ruby/security/advisories/new).
2. Fill in the form. Only the project's maintainers can see what you send.

If you aren't sure that a problem is a vulnerability, report it privately anyway.

## What to include

- The **Stryker (for Ruby)** version, from `stryker --version`.
- Your system: its operating system and processor, and your Ruby version.
- How to reproduce the problem: the project's configuration, the command you ran, and what happened.

## Which versions get fixes

[The README's Compatibility section](README.md#compatibility) lists the Ruby versions and systems that **Stryker (for Ruby)** supports. It makes no promise that an earlier release gets a fix. A fix ships in a new release, so install [the latest release](https://github.com/setdef/stryker_for_ruby/releases/latest).
